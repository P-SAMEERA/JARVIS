Below is a **self-contained example** that shows how a program can *write* (i.e., generate) another piece of source code.  
The example is written in Python because it's easy to run on any platform, but the same ideas work in virtually any language.

---

## 1. What the example does

1. **`generator.py`** - the "code-that-codes".  
   *It creates a new file called `hello_world.py` and writes a tiny Python program into it.*

2. **`hello_world.py`** - the code that was generated.  
   *When you run it, it simply prints "Hello, World!".*

Running `generator.py` once will produce `hello_world.py`. After that you can execute the generated file independently.

---

## 2. The generator code (`generator.py`)

```python
#!/usr/bin/env python3
"""
generator.py

A tiny "code-that-codes" example.
It writes a new Python source file (hello_world.py) that prints
'Hello, World!' when executed.

You can adapt the TEMPLATE string to generate any kind of code
(e.g., C, JavaScript, HTML, ...) - just change the file extension
and the content of the string.
"""

import os
from datetime import datetime

# ----------------------------------------------------------------------
# 1️⃣  Template for the code we want to generate
# ----------------------------------------------------------------------
# The triple-quoted string is the *exact* source code that will be written
# to the new file.  Use {placeholders} if you want to inject values.
TEMPLATE = """#!/usr/bin/env python3
\"\"\"
hello_world.py

Generated on: {timestamp}
\"\"\"

def main():
    print("Hello, World!")

if __name__ == "__main__":
    main()
"""

# ----------------------------------------------------------------------
# 2️⃣  Helper: write the file
# ----------------------------------------------------------------------
def write_generated_file(filename: str, content: str) -> None:
    """
    Writes *content* to *filename*.
    If the file already exists it will be overwritten.
    """
    with open(filename, "w", encoding="utf-8") as f:
        f.write(content)
    # Make the generated script executable on POSIX systems
    if os.name != "nt":          # skip on Windows
        os.chmod(filename, 0o755)
    print(f"✅  Generated file: {filename}")

# ----------------------------------------------------------------------
# 3️⃣  Main driver - fill the template and write the file
# ----------------------------------------------------------------------
def main():
    # Information we want to embed in the generated code
    timestamp = datetime.utcnow().strftime("%Y-%m-%d %H:%M:%S UTC")

    # Fill the placeholders in the template
    generated_source = TEMPLATE.format(timestamp=timestamp)

    # Choose the output file name
    out_file = "hello_world.py"

    # Write the file
    write_generated_file(out_file, generated_source)


if __name__ == "__main__":
    main()
```

### How it works

| Step | What happens |
|------|--------------|
| **Template** | `TEMPLATE` holds the exact source code you want to generate. You can use Python's `str.format` placeholders (`{timestamp}`) to inject dynamic data. |
| **Formatting** | `generated_source = TEMPLATE.format(timestamp=timestamp)` substitutes the placeholder with the current UTC time. |
| **Writing** | `write_generated_file()` opens (or creates) `hello_world.py`, writes the formatted string, and makes the file executable on Unix-like systems (`chmod 755`). |
| **Run** | When you execute `generator.py`, you get a brand-new `hello_world.py`. Running that file prints "Hello, World!". |

---

## 3. Running the example

```bash
# 1️⃣  Save the generator script
$ cat > generator.py <<'EOF'
# (paste the whole script from above here)
EOF
$ chmod +x generator.py

# 2️⃣  Execute the generator
$ ./generator.py
✅  Generated file: hello_world.py

# 3️⃣  Run the generated script
$ ./hello_world.py
Hello, World!
```

You should see the timestamp line inside `hello_world.py` as a comment, proving that the file was indeed generated at runtime.

## 4. Extending the idea

### a) Generate other languages
Just change the extension and the template string. Example - generate a simple **C** program:

```python
C_TEMPLATE = """#include <stdio.h>

int main(void) {{
    printf("Hello from C!\\n");
    return 0;
}}
"""

# later ...
write_generated_file("hello.c", C_TEMPLATE)
```

### b) Parameterise the generated code
You can expose a tiny CLI for the generator:

```python
import argparse

parser = argparse.ArgumentParser(description="Simple code generator")
parser.add_argument("--lang", choices=["python", "c"], default="python")
parser.add_argument("--msg", default="Hello, World!")
args = parser.parse_args()
```

...and then use `args.msg` inside the template to customise the printed message.

### c) Generate multiple files at once
If you need a whole project scaffold, store each file's template in a dictionary and loop over it:

```python
templates = {
    "main.py": PYTHON_MAIN_TEMPLATE,
    "utils.py": PYTHON_UTILS_TEMPLATE,
    "README.md": README_TEMPLATE,
}
for name, tmpl in templates.items():
    write_generated_file(name, tmpl.format(...))
```

## 5. TL;DR - One-liner version (for fun)

If you just want a *quine* (a program that prints its own source), here's a classic Python one-liner:

```python
s='s=%r;print(s%%s)';print(s%s)
```

Running it prints the exact source code again. That's the ultimate "code that codes the code".

* The same pattern works in other host languages (JavaScript, Ruby, Go, ...) - the only difference is the file-IO API.
